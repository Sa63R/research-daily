# 公开日报停止更新说明

本项目曾以“绿群日报”的形式持续发布 CS 保研群聊摘要。维护者现已停止每日生成、上传和 Telegram 播报，不再承诺内容更新频率。

项目继续保留为日报生成工具：使用者可以提供自己的 ChatLab JSON，在本地执行匿名化、结构化提取、Markdown 渲染和风险检查。Cloudflare R2、Telegram、GitHub Pages 和定时任务均为可选集成。

[历史 Pages 网站](https://csbaoyan.icelon.top)仅用于展示过去的生成效果。历史页面可能包含已经失效的招生时间、项目状态和个人经验，不应作为当前决策依据。

## 历史背景

早期日报依赖聊天记录导出和每日运维，曾因 QQ 强制下线、账号限制以及手动维护成本而暂停。之后虽然通过本地只读热镜像恢复过自动生成，但长期运营仍需要持续承担模型调用、隐私复核、发布基础设施和故障处理成本，因此最终停止公开日更。

停止的是维护者运营的日报服务，不是生成器本身。自行使用和部署方式见[README](../README.md)与[可选集成及部署指南](./deploy-guide.md)。
